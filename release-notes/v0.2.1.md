# Release Notes - v0.2.1

**Release Date:** January 15, 2026

## 🎯 Build Optimization Update

This patch release introduces code splitting for built functions, addressing the 20MB maximum function size limit imposed by Cloudflare Pages Functions.

## ✨ What's New

### Code Splitting for Functions

- **Automatic Code Splitting**: Built functions are now automatically split into smaller chunks, significantly reducing individual function output sizes
- **Cloudflare Compliance**: Prevents hitting the 20MB maximum function size limit that could occur with larger action files
- **Smaller Bundle Sizes**: Overall reduction in bundled output size through better code organization

## 🐛 Bug Fixes

- Fixed an issue where large action files could exceed Cloudflare's 20MB function size limit
- Improved build output optimization for better deployment reliability

## 📦 Upgrade Guide

Simply update to the latest version:

```bash
bun update frame-master-plugin-cloudflare-pages-functions-action
```

No configuration changes are required - code splitting is automatically enabled.

## 📋 Requirements

- **frame-master**: ^3.0.2
- **Bun**: >=1.2.0
