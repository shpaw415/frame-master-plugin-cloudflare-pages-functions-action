# Release Notes - v0.2.0

**Release Date:** December 12, 2025

## 🎯 Frame Master 3.0.x Compatibility Update

This release updates the plugin to work with **Frame Master 3.0.x**, bringing improved developer experience and new capabilities for handling raw Cloudflare Pages Functions.

## ✨ What's New

### New `"no action"` Directive

You can now exclude specific files from action transpilation by adding the `"no action"` directive at the top of the file. This is useful when you need to write raw Cloudflare Pages Functions that bypass the action system:

```typescript
"no action";

import type { EventContext } from "@cloudflare/workers-types";

export async function onRequestGet(params: EventContext<Env, any, any>) {
  return new Response("Hello from raw Cloudflare Pages Function!", {
    headers: { "content-type": "text/plain" },
  });
}
```

Files with this directive will be built to the `functions/` directory as-is, giving you full control over the Cloudflare Pages Functions API when needed.

### Improved Developer Experience

- **Better Build Integration**: Streamlined integration with Frame Master's new build system
- **Enhanced File Watching**: More reliable file system watching with `directiveToolSingleton` for directive detection
- **Cleaner Logs**: Improved logging with verbose mode support via `verboseLog`

## 🔄 Breaking Changes

### Peer Dependency Update

- **frame-master**: Updated from `^2.x` to `^3.0.2`

Make sure to update your Frame Master installation:

```bash
bun update frame-master
```

## 📦 Upgrade Guide

1. Update Frame Master to 3.0.x:

   ```bash
   bun update frame-master
   ```

2. Update this plugin:

   ```bash
   bun update frame-master-plugin-cloudflare-pages-functions-action
   ```

3. No configuration changes required - your existing `frame-master.config.ts` will continue to work.
